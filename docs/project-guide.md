# 节目手册

写新稿、规划选题时读这份。它回答三件事：**这个节目是什么、一集怎么搭、哪些话不能说。**

> ⚠️ 第三节的十种情景是我按心理科普常见场景起的**候选**，不是你手上那份大纲。
> 你原来的稿子和情景库整理好之后，直接替换掉那张表 —— 结构留着，内容换成你的。

---

## 一、定位

| 项 | 内容 |
|---|---|
| 一句话 | 把心理学概念放进一个具体的生活场景里，让听众在别人的对话里认出自己 |
| 听众 | 没有心理学背景、正在某个关系里觉得别扭但说不清的人 |
| 单集时长 | 8–12 分钟（后期可到 15） |
| 一集讲几个概念 | **一个**。多出来的写进下一集的 idea |
| 形式 | 对话体，两个角色，一个卡住、一个陪着往下走 |
| 不做什么 | 不做诊断、不做咨询示范、不做"三招治好"、不念论文 |

判断一个选题该不该做，只问一句：**听众听完，能不能说出"原来那种感觉有个名字"？** 能，就做；只是"有道理"，不做。

## 二、一集的五段

模板第 4 节那个大纲，就是这五段。每段有它必须完成的活，缺一段这集就散。

| 段 | 干什么 | 建议时长 | 写不出来说明什么 |
|---|---|---|---|
| 1. 开场 | 直接扔进场景的一句台词，不介绍、不铺垫 | 30–60 秒 | 你还没想好这一集到底讲谁的什么时刻 |
| 2. 对话探索 | 两个角色把这件事聊歪、聊僵、聊到卡住 | 3–5 分钟 | 情景是假的，或者冲突不够具体 |
| 3. 概念解释 | 停下来，把刚才发生的事命名，给定义和边界 | 2–3 分钟 | 资料核查没做完 |
| 4. 回到情景 | 用新名字重看刚才那段对话，角色做出不同的选择 | 2 分钟 | 概念和情景没真正接上，只是在旁边讲道理 |
| 5. 小练习与结尾 | 一个当场能做的小动作 + 一句不煽情的收尾 | 1 分钟 | 想不出练习，通常是概念太大 |

**第 3 段最容易写坏。** 它不是"科普时间"，是"刚才那段对话的注解" —— 每讲一句定义，都要能指回第 2 段的具体台词。做不到就说明这个概念不该在这一集讲。

## 三、十种情景（候选，替换成你的）

`scenario_id` 就是模板 front matter 里那个字段，一集只填一个。

| ID | 类型 | 情景 | 卡在哪 | 可讲的概念 |
|---|---|---|---|---|
| SC01 | 家庭 | 青春期的孩子说「我不想上学了」，家长越劝越僵 | 想解决问题，对方要的是被听见 | 共情与说服的区别、控制感 |
| SC02 | 亲密关系 | 一方在讲今天多委屈，另一方开始分析该怎么办 | 两个人不在同一个频道，都觉得自己在帮忙 | 情绪需求 vs 问题解决、修复尝试 |
| SC03 | 师生 | 学生说「我就是学不进去」，老师给了方法，学生更沉默 | 反复失败之后，人先放弃的是"我能行" | 情绪命名、习得性无助、自我效能 |
| SC04 | 职场 | 会上被当众指出错误，之后一整天都在想那句话 | 分不清"我做错了"和"我这个人不行" | 羞耻 vs 内疚、防御 |
| SC05 | 朋友 | 永远是那个听别人倾诉的人，自己从不开口 | 怕一开口就成了负担 | 边界、讨好、情绪劳动 |
| SC06 | 自我 | 深夜复盘白天的对话，把每句话重放一遍 | 以为在反思，其实在原地打转 | 反刍思维、自我关怀 |
| SC07 | 照护 | 老人反复问同一件事，照护者第三次回答时失控了 | 累到极点又觉得自己不该烦 | 记忆与焦虑、照护者耗竭 |
| SC08 | 合租/室友 | 想说「能不能小声点」，说了三次都没说出口 | 提要求这件事本身就让人紧张 | 边界、冲突回避 |
| SC09 | 朋友 | 朋友给了一堆建议，听完更焦虑了 | 建议本身会拿走对方的主权 | 建议的副作用、自主性 |
| SC10 | 公共场合 | 被插队，当场没吭声，回家气了一晚上 | 事后才想起该说什么 | 基本归因错误、敌意归因 |

`scenario_type` 就用这六类：`家庭` / `亲密关系` / `师生` / `职场` / `照护` / `自我` / `公共`。

## 四、抽选与轮换

不轮换的话，十集之后你会发现自己在重复讲同一件事。

- **连续两集不用同一个 `scenario_id`。**
- **五集之内不重复 `core_concept`。** 相关概念算重复（"羞耻"和"内疚"隔三集再讲）。
- **同一种 `character_relationship` 最多连着两集。**
- **每做三集，回看 `index.csv` 一次。** 看 `core_concept` 那列是不是在往一个方向收窄 —— 收窄不一定是坏事，但要是无意识的就坏了。

## 五、科普边界（写稿时逐条过）

1. **不诊断。** 不说"你这是焦虑症""你有回避型依恋"。说"这种反应常被叫作回避"。
2. **不贴人格标签。** 描述行为，不定义人。"他在这种场合会先退一步"，不是"他是个回避的人"。
3. **不承诺疗效。** 不出现"照做就能好""三周见效"。
4. **不替代治疗。** 片尾固定一句：内容用于科普，不构成诊断或治疗建议。
5. **引用要能查。** 作者 + 年份 + 出处，写进第 2 节"已核实来源"。查不到就删掉那句，不写"研究表明"。
6. **危机内容要留出口。** 涉及自伤、自杀、虐待、成瘾的集数，片尾必须给求助渠道（如当地心理援助热线），并且不在节目里描述具体方法。
7. **不给角色下判决。** 对话里那个"做错的人"也要有他的道理，否则听众会关掉 —— 没人愿意听自己被审判。

## 六、口语标准

稿子是要念出来的，不是读的。

- 一句话不超过 25 个字，超过就断。
- 不写"首先/其次/综上所述"，写"然后呢""你看""问题是"。
- 术语第一次出现必须当场用一句人话解释，不能留到后面。
- 数字和年份能省就省，除非它本身是重点。
- 念一遍再交稿。念着别扭的地方，听众一定听不出来在说什么。
