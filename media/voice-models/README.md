# voice-models

RVC 音色模型。**这里是"变声器"的零件，不是朗读引擎** —— 它们不能把文字变成声音，
只能把一段已有的人声换成另一个音色。用法见下面第四节。

模型不进 git（见 `.gitignore`），换机器要单独拷。

---

## 一、里面有什么

| 目录 | 模型文件 | 索引文件 | 来源 |
|---|---|---|---|
| `yelan/` | `yelan.pth` 52.6 MB | `yelan_added_IVF444_Flat_nprobe_1_yelan_v2.index` 52.2 MB | 百度网盘下载包，2026-11-01 解出 |
| `ganyu/` | `ys_ganyu.pth` 52.7 MB | `ys_ganyu_added_IVF717_Flat_nprobe_1_ys_ganyu_v2.index` 84.3 MB | 同上，本来就是散文件 |

两个 `.pth` 的内部参数（从文件里读出来的，不是猜的）：

| 项 | 值 | 含义 |
|---|---|---|
| `version` | `v2` | RVC v2 架构。v1 的 WebUI 加载不了，反过来也不行 |
| `sr` | `40k` | 训练采样率 40 kHz。**不是 48k**，转换时选错会明显发闷 |
| `f0` | `1` | 训练时带音高引导，适合说话和唱歌 |
| `epoch` | `500` | 训练轮数，常规量级 |
| `config` | `[1025,32,192,192,768,2,6,3,0,"1"]` | 架构参数，末尾 `"1"` 也是 v2 标志 |

`.index` 是 FAISS 特征索引（`IndexFlat`，nprobe=1），用来在转换时"找相似音素"，
减轻漏字和口音漂移。**它跟 `.pth` 必须配套** —— 拿 A 的模型配 B 的索引，出来是混的。

## 二、⚠️ 版权：这两个音色不能拿去变现

这是给**能变现的播客**用的项目，所以这条必须写在最前面：

- **角色是米哈游的 IP**（《原神》夜兰、甘雨）。角色形象、名字、设定都归米哈游。
- **声音本身属于配音演员**。《民法典》第 1023 条把声音纳入人格权保护，参照肖像权 —— 未经许可克隆他人声音用于商业传播，是可以被追责的。
- **2025-09-01 起**，《人工智能生成合成内容标识办法》要求发布 AI 生成内容时主动声明并打标识。不标是违规，标了也不代表有权用这个音色。

结论：**内部试听、做样片、自己听着玩，没问题；挂上广告、开付费、接商单，不要用这两个音色。**
真要做商业版，用自己录的声音、或明确买了商用授权的音色。

## 四、怎么用（关键：RVC 不会朗读）

流程是**两段**，不是一段：

```text
文字稿  ──TTS──▶  一段普通人声  ──RVC──▶  夜兰/甘雨的声音
        （可选）                  （变声）
```

或者跳过 TTS，自己念：

```text
文字稿  ──自己念──▶  录音  ──RVC──▶  角色音色
```

**第一步必须有"一段人声"。** 直接丢文字给 RVC，它不认。

### 4.1 装工具

二选一，都开源：

- **Applio** —— 现在更省事，自带安装脚本，界面里能直接选 `.pth` + `.index`。推荐先试这个。
- **RVC WebUI**（原版）—— 功能最全，但要手动装 Python 依赖，路径约定更死板。

装完把文件放到它认的目录（以 RVC WebUI 为例）：

```text
assets/weights/yelan.pth              ← .pth 放这里
logs/yelan/…_v2.index                 ← .index 放这里（或界面上直接填绝对路径）
```

Applio 允许在界面上直接指定绝对路径，就不用搬文件，指到本目录即可。

### 4.2 转换参数

对"说话"（不是唱歌），这几个值先这么设，再微调：

| 参数 | 建议值 | 为什么 |
|---|---|---|
| 变调 pitch | 男声→女声 `+12`，同性别 `0`，女声→男声 `-12` | 夜兰、甘雨都是女声，源头若是男声必须 +12，否则出来是"男低音版" |
| 索引率 index rate | `0.5`–`0.75` | 太高会带出训练集的杂音，太低会漏字。从 0.6 起 |
| 保护 protect | `0.33` | 保护清音和呼吸声，别调到 0.5 以上，会闷 |
| 采样率 | 跟模型一致 `40k` | 选 48k 会重采样，白白掉细节 |
| f0 算法 | `rmvpe` | 比 harvest/pm 准，说话场景够用 |

### 4.3 验收标准

转完不要只听"像不像"，按这三条过：

1. **字没漏。** 拿稿子对一遍，尤其句尾和数字。
2. **没有金属音/电音。** 有，先把 index rate 降到 0.5 再试。
3. **情绪还在。** 如果听起来像念经，说明源头就太平 —— 先改 TTS 或重录，RVC 补不回情绪。

## 五、和项目其它部分的关系

- `media/voice-samples/` 放**音频样本**（选音试听用），这里放**模型文件**，别混。
- 定了用哪个音色，去 `docs/voice-guide.md` 的角色档案表加一行，写清模型路径和授权状态。
- 每集成品进 `media/episode-audio/`，命名 `EPxxx-成品.mp3`。
- 发布前回 `docs/platforms.md` 第三节过一遍 AI 标识要求。
